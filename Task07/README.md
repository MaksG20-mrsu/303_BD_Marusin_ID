# Лабораторная работа 7

Консольный сценарий и веб-страница показывают услуги, оказанные мастерами СТО. Данные берутся из базы лабораторной работы 6. Можно вывести все работы или выбрать мастера по номеру.

## Запуск

Нужны PHP 8 с расширением PDO SQLite (pdo_sqlite) и консольный клиент SQLite 3.38 или новее.

Из корня репозитория один раз создайте учебную базу.

~~~sh
sqlite3 -batch -bail Task07/sto.db ".read Task07/db_init.sql"
~~~

Для консольного варианта запустите команду ниже. После списка мастеров введите номер или нажмите Enter.

~~~sh
php Task07/task7_cli.php
~~~

В Windows для отображения русских букв и рамки таблицы в cmd предварительно выполните команду chcp 65001.

Для веб-варианта запустите встроенный сервер PHP и откройте http://127.0.0.1:8000/. В форме выберите мастера или пункт «Все мастера».

~~~sh
php -S 127.0.0.1:8000 -t Task07/public
~~~

Оба варианта используют подготовленные запросы из repository.php. Файл базы sto.db хранится в каталоге Task07 рядом с SQL-скриптом.
