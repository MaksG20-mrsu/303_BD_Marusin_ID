# Лабораторная работа 8

Веб-формы СТО позволяют добавить мастера с перечнем услуг, сохранить смену и предварительно записать автомобиль на обслуживание.

## Запуск

Нужен PHP 8 с расширением pdo_sqlite. Из корня репозитория выполните команду.

~~~sh
php -S 127.0.0.1:8000 -t Task08/public
~~~

Откройте http://127.0.0.1:8000/. Ссылки на три формы находятся на главной странице. Готовая база находится в data/sto.db.

В форме записи выберите услугу, мастера, дату и свободное время. Укажите ФИО, телефон, госномер, марку и модель. Если будущих смен у мастера нет, сначала добавьте смену в график.

Для повторной проверки на чистых данных можно создать учебную базу заново из data/db_init.sql. Команда заменит содержимое базы исходными данными. Для неё нужен sqlite3 версии 3.38 или новее.

~~~sh
sqlite3 -batch -bail Task08/data/sto.db ".read Task08/data/db_init.sql"
~~~
