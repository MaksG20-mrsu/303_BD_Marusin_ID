# Лабораторная работа 1

## Структура файлов данных

### movies.csv
Фильмы. Формат CSV, разделитель — запятая, первая строка — заголовок. Если название содержит запятую, оно заключено в кавычки.
- `movieId` — идентификатор фильма;
- `title` — название фильма, в скобках указан год выхода;
- `genres` — жанры фильма через символ `|`.

### ratings.csv
Оценки фильмов пользователями. Формат CSV, разделитель — запятая, первая строка — заголовок.
- `userId` — идентификатор пользователя;
- `movieId` — идентификатор фильма;
- `rating` — оценка от 0.5 до 5.0;
- `timestamp` — время выставления оценки (Unix time, секунды с 01.01.1970).

### tags.csv
Теги, которые пользователи ставят фильмам. Формат CSV, разделитель — запятая, первая строка — заголовок.
- `userId` — идентификатор пользователя;
- `movieId` — идентификатор фильма;
- `tag` — тег (слово или короткая фраза);
- `timestamp` — время добавления тега (Unix time).

### users.txt
Пользователи. Поля разделены символом `|`, заголовка нет. Поля по порядку:
1. идентификатор пользователя;
2. имя и фамилия;
3. email;
4. пол (`male` или `female`);
5. дата регистрации в формате ГГГГ-ММ-ДД;
6. род занятий (одно из значений из `occupation.txt`).

### genres.txt
Список жанров фильмов, по одному в строке.

### occupation.txt
Список видов деятельности пользователей, по одному в строке.

## Остальные файлы
- `ratings_count.txt` — минимальный и максимальный `userId` из `ratings.csv` и количество строк с каждым из них.
- `sqlite.txt` — версия SQLite и режимы вывода утилиты `sqlite3`.
